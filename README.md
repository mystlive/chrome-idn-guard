# 文字なりすましURLチェッカー — Chrome拡張機能 試作版 v0.2.0

Chrome / Windows用の、UnicodeホモグラフによるURL偽装を説明するローカル判定拡張機能です。
**外部通信なし、外部ライブラリなし、閲覧履歴の保存なし。** ソースコードを全て同梱しています。
本試作はChrome Web Store登録・第三者によるセキュリティ監査を行っていません。

## インストール方法

1. ZIPを解凍する。
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を選択する。
4. 解凍した中の **chrome-extension** フォルダを指定する（manifest.jsonがある場所）。
5. ツールバーの拡張機能一覧から「文字なりすましURLチェッカー」をピン留めすると便利です。
6. 拡張機能のアイコンをクリックすると現在のページを検査できます。サイトへ移動する前に調べたい場合は、ポップアップ上部へURLを貼り付けて検査してください。
7. 自動監視する場合は拡張機能内の「自動監視を有効化」を押し、Chromeの権限確認に同意してください。

## 表示の意味

- **赤 !**: 同じドメイン構成要素内のラテン文字とキリル/ギリシャ文字の混在、または既知サービスのドメインとの文字上の類似。注意。
- **黄 ?**: 他の文字体系だけで作られた構成要素が、ラテン文字だけに見える可能性。
- **青 IDN**: 国際化ドメイン。危険判定ではありません。
- **バッジなし**: 現行の簡易規則では異常なし、または検査対象外。**安全を保証しません。**

## 権限とプライバシー（特に重要）

| 権限 | 必須 | 用途 |
|---|---|---|
| `activeTab` | はい | アイコンをクリックしたタブのURLを一時的に取得。通常、インストール時の警告なし |
| `tabs` | いいえ（利用者が任意に許可） | 自動監視時のみタブのURLを取得し警告バッジ表示。Chromeは「閲覧履歴の読み取り」と表示 |

- `host_permissions` は指定せず、全サイトへの常時アクセスを要求しません。
- `history`, `webRequest`, `cookies`, `scripting`, `storage`, `declarativeNetRequest` 権限を使用しません。
- ページの本文、フォーム、パスワード、Cookie、スクリーンショットを取得しません。
- URLは現在のタブまたは利用者が貼り付けたURLを調べるためにメモリ内で短時間扱います。URL・分析結果は記録・送信しません。
- 外部CDN、Google Analytics、通信API、遠隔実行コードは使用しません。
- 自動監視はボタンで無効化でき、任意の `tabs` 権限も実際に削除します。
- CSPに `connect-src 'none'` を設定し、通信機能を意図的に遮断しています。
- 自動更新機能はありません（ローカル読み込みのため）。更新時はソースを比較できます。

## 実装と制約

- `analyzer.js`: URLのドメイン部分のみを取り出して分析します。
- `punycode.js`: Punycode A-label (`xn--`) の復号化処理を自前実装しています。
- `confusables-basic.js`: キリル文字・ギリシャ文字の**主要な類似文字のみ**を搭載した試験用の対応表です。
- `background.js`: 任意の `tabs` 権限が許された場合だけURL変更時にアイコン警告を更新します。
- `popup.*`: 現在のタブ、または貼り付けたURLの文字体系・Unicode値・判定理由を表示します。貼り付け検査は移動前の確認に使えます。

**Unicode UTS #39の完全準拠実装ではありません。** データは網羅的でなく、正規サイトの誤検知、悪意のあるサイトの見逃しがあります。ドメインのレピュテーション、証明書の検証、ブラウザのSafe Browsingなどの代替になりません。
この拡張機能は訪問を遮断しません。自動監視の警告は移動後ですが、URLを貼り付ければ移動前にも検査できます。

対象外の例: ASCIIのみのタイプミス、Unicodeの結合文字の一部、他言語の類似文字、欺瞞的なサブドメイン構成（`paypal.com.evil.example`）など。

## テスト

Node.js 22以上を使用。インストールするnpm依存パッケージはありません。

```text
node --test tests/*.mjs
```

対象テスト例: `pаypal.com` (キリルa)、`ѕсоре.com` (全部キリル文字)、`пример.рф` (ロシア語の正規表記)、`例え.テスト`、通常のASCIIドメイン。

`https://pаypal.com` 等の疑わしい実ドメインには**テスト目的でもアクセスしない**でください。検証は同梱のテストプログラム内で行います。

## 信頼性を公開時にさらに高める対応

- 著名ドメイン一覧と類似文字テーブルを監査可能なデータとして別管理し、テストを増やす。
- Unicode UTS #39 v18.0.0の公式 confusables データをライセンス・更新手続きとともに同梱し、誤検知を評価する。
- オープンソースライセンス、変更履歴、署名付きリリース、再現可能ビルド、第三者監査結果、プライバシーポリシーを公開する。
- Chrome Web Store公開時は審査を経て検証可能な開発者情報を提示する。**ストア審査だけでは安全性の証明になりません。**

公式参照:
- Chrome API: https://developer.chrome.com/docs/extensions/reference/api/permissions
- Chrome権限: https://developer.chrome.com/docs/extensions/develop/concepts/activeTab
- Unicode UTS #39: https://www.unicode.org/reports/tr39/

## 実URLを使ったブラウザ試験（v0.1.1追加）

前版の単体テストのみでは、Chromeアドレスバーに偽装ドメインを表示した際の動作は確認できません。v0.1.1では、安全な `.test` ドメインを127.0.0.1へ割り当てる **実ページのローカル検証環境** を追加しました。

詳細は **`test-site/README.md`** を参照。Windowsで `test-site/start-local-site.cmd`、次に `test-site/open-test-chrome.cmd` をダブルクリックすると、偽装ドメインの比較ページをChromeで検証できます。

- 検証環境はPython標準ライブラリのみ、実在ドメインへの接続は不要です。
- Chrome本体が偽装URLをPunycode表示する場合もあります。
- 自動警告は `tabs` 権限許可時のみ有効。通常モードではクリックして検査します。
- 追加テスト: `python -m unittest discover -s tests -p 'test_local_server.py'` と `node --test tests/*.mjs`。
- **Windows Chromeの実機操作は未検証です。**
