# Chrome実地検証用・ローカル模擬サイト

**ブラウザの実URLに偽装文字を含めて、拡張機能を検査するためのものです。** ページ本文の文字列だけを模したテストではありません。

## 準備（Windows・Chrome）

1. このフォルダの `start-local-site.cmd` をダブルクリック。Python 3（標準ライブラリのみ）が必要です。黒いウィンドウは開いたままにしてください。
2. `open-test-chrome.cmd` をダブルクリック。**専用の別Chromeプロファイル**が開き、 `http://paypal.test:8765/` が表示されます。
3. そのChromeで `chrome://extensions` → 「デベロッパー モード」→「パッケージ化されていない拡張機能を読み込む」→ **ZIP解凍後の `chrome-extension` フォルダ**を選択してください。普段のChromeに入っていても、この専用プロファイルには別途必要です。
4. 拡張機能のポップアップで「移動前のリンク確認」を有効にし、Chromeの全サイトアクセス権限へ同意します。ページ内の国際化ドメインリンクに目印が表示されます。
5. テストページ上の5ケースをクリックし、移動前の確認画面で判定を見てください。「確認して続ける」を選ぶと移動できます。URLを直接アドレスバーへ入力した場合は、読み込み開始後に画面を覆って確認を表示します。
6. ツールバーの自動バッジも試す場合は、ポップアップの「自動監視を有効化」を別に選び、`tabs` 権限へ同意してください。

| テストURLのホスト部分 | 期待する判定 | 検査内容 |
|---|---|---|
| `paypal.test` | 正常（バッジなし） | 英数字のみ |
| `pаypal.test` | 警戒（!） | 2文字目だけキリル文字 `а`（U+0430） |
| `ѕсоре.test` | 注意（?） | 5文字全部キリル文字 |
| `gοοgle.test` | 警戒（!） | ギリシャ文字 `ο`（U+03BF）を混在 |
| `пример.test` | IDN（青） | 通常のロシア語表記を危険と決めつけない |

注：いずれも **`http://<上記ドメイン>:8765/`** が完全なテストURLです。Chromeは偽装を防ぐため一部のURLを `xn--` のPunycode表記で表示する場合があります。その場合も拡張機能は内部的にUnicodeへ復号して分析します。

## なぜ専用Chromeプロファイルなのか

通常のChrome設定やWindowsのhostsファイルを変更せずにテストするためです。起動オプション `--host-resolver-rules` は、**指定した5つの `.test` ドメインだけ**を `127.0.0.1` に割り当てます。通常ブラウザや他のアプリには影響しません。管理者権限も不要です。

- テストサーバは **127.0.0.1:8765 にだけバインド**し、LANやインターネットに公開しません。
- テストページはフォーム、JavaScript、外部CSS、画像、外部APIを持たず、受信URLのログも保存しません。
- ページ上のリンクはこの5サイトの間だけを遷移します。
- Chrome自体は独自に通信することがあります。「専用Chromeのネットワーク全体が完全オフライン」とは意味しません。
- テストサイトはHTTPです。これはローカルの文字判定実験用であり、本番サイトの安全性を検証するものではありません。
- 一部のセキュリティ設定・HTTPプロキシ・ChromeのHTTPS優先モードで表示できない場合があります。その場合は `http://` の明示、別プロファイルが開いているか、サーバウィンドウの状態を確認してください。**セキュリティ機能の無効化は推奨しません。**

## 終了・後始末

- サーバの黒いウィンドウで `Ctrl+C`、またはウィンドウを閉じて停止します。
- テスト専用Chromeを閉じてください。
- 専用プロファイルを消す場合は、Chrome終了後に `%LOCALAPPDATA%\DomainGuardianLabChromeProfile` フォルダを手動で削除できます。
- Windowsのhostsファイル、ファイアウォール、証明書ストアは変更していません。

## トラブルシュート

- `ERR_NAME_NOT_RESOLVED`：`open-test-chrome.cmd` が起動した専用プロファイルか確認してください。
- `ERR_CONNECTION_REFUSED`：サーバが起動しているか、ポート `8765` が占有されていないか確認してください。
- リンクの目印が出ない：拡張機能を**専用プロファイルにも**導入し、「移動前のリンク確認」を有効化してください。
- Chromeが `xn--` で表示：ブラウザ自身の保護動作です。異常ではありません。
